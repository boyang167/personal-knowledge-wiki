# Publish

仅存放 **经人工审核**、可对外分享的知识副本。

## 规则

1. 不得从 `raw/` 或 `wiki/` 自动同步到此目录。
2. 迁入前确认：无内部/隐私/秘密信息；结论与 `sources` 一致。
3. 建议保持与 wiki 相同的 frontmatter，并将 `status` 设为 `reviewed`。

## 操作示例

人工确认 wiki 页面无误后，复制到 `publish/` 并保持相对主题结构，例如：

`wiki/big-data/data-platform-architecture.md` → `publish/big-data/data-platform-architecture.md`
