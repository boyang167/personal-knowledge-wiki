# 抗体药物 CMC 项目阶段与 IND 活动路线

## 结论摘要

- CMC 计划需要把细胞系、细胞库、分析方法、DS/DP 工艺、GMP 生产、稳定性和申报活动串成可追踪的阶段链。
- 美国 12 个月 IND CMC 活动在原始笔记中被拆成多个并行或衔接任务，不能只理解为单一生产流程。
- 工艺开发和分析方法开发会影响后续的工程运行、GMP 批次、稳定性与申报资料准备。
- 本页是项目管理视角的结构化摘要，不替代法规、质量体系或具体申报策略。

## 阶段结构

| 阶段 | 典型工作包 |
|------|------------|
| 项目启动 | 项目范围、计划、职责和关键决策点 |
| 细胞系构建与开发 | 细胞系建立、筛选和表征 |
| 细胞库建立与检测 | 细胞库建立、检测和放行相关活动 |
| 分析方法开发与确认 | 方法转移、开发与 qualification |
| DS 工艺开发 | 原液生产工艺、参数和规模放大 |
| DP 配方与生产工艺开发 | 配方、灌装和制剂工艺 |
| 非 GMP DS 生产 | 工艺验证前的材料和批次支持 |
| DP 工程运行 | 工程批、设备和流程验证准备 |
| cGMP DS / DP 生产 | 临床申报所需的受控生产活动 |
| 稳定性研究 | 稳定性方案、样品和数据汇总 |
| IND 申报附加活动 | 资料准备、质量文件和补充证明 |
| 项目收尾 | 归档、总结、遗留项和后续计划 |

## 依赖关系

```text
细胞系/细胞库
      ├──> 分析方法
      └──> DS 工艺开发 ──> 非 GMP / 工程运行 ──> cGMP DS
                                     └────────────> 稳定性
DP 配方与工艺 ───────────────────────> cGMP DP ──> 稳定性
所有活动 ───────────────────────────────────────> IND 资料与收尾
```

## 使用这份路线图时的检查点

- 每个工作包都应有输入、输出、责任人、计划时间和可追踪记录。
- 工艺、分析方法和生产批次之间要建立样品、数据和版本的追溯关系。
- 申报活动不仅依赖生产结果，也依赖方法、稳定性、质量文件和变更记录的完整性。
- 中国申报活动在原始笔记中单列，不能默认与美国 12 个月活动完全等价。

## 待核实

- 具体时间线、法规要求、批次数量和放行标准没有在本页展开，应以项目质量体系和适用监管要求为准。
