# 机器学习项目流程与算法地图

## 结论摘要

- 项目拆成启动、特征工程、由易到难建模、训练优化和服务上线。训练过程和服务过程不是两件无关的事。
- 监督学习覆盖分类、概率图和回归；无监督学习覆盖聚类、主题、关联和降维。
- 可避免的偏差和方差要分开处理。类别不平衡不能只看准确率，ROC 与 PR 都要看。
- 具体公式和代码片段留在原笔记，本页只保留地图。

## 项目阶段

| 阶段 | 关注点 |
|------|--------|
| 启动 | 目标、使用习惯、性能衡量、系统评估、个性化和局限 |
| 特征 | 数据从哪来、成本、偏向、平衡，以及特征是不是直接测量量 |
| 建模 | 先简单模型，再增加复杂度 |
| 训练与优化 | 系统性地调参，而不是只换一个模型名 |
| 上线 | 训练指标和服务效果可能不一致，要考虑可解释性和改动取舍 |

## 算法分组

| 类型 | 代表 |
|------|------|
| 线性与非线性分类 | 感知机、KNN、朴素贝叶斯、逻辑回归、最大熵、SVM、决策树（ID3、C4.5、CART） |
| 集成 | AdaBoost、GBDT、XGBoost、随机森林、Stacking。XGBoost 可以看成带正则的梯度提升实现，基学习器可以是树，也可以是线性模型 |
| 概率图 | HMM、MEMM、CRF |
| 回归 | 线性回归、树回归、Ridge、Lasso |
| 聚类 | K-means、二分 K-means、GMM、层次聚类、密度聚类、谱聚类 |
| 主题与关联 | pLSA、LDA；Apriori、FP-growth |
| 降维 | PCA、SVD、LDA、LLE |

后面还有 EM、LightGBM、Bagging/Boosting 对比，以及过拟合、欠拟合、L1/L2 和交叉熵的问答提纲。那些条目适合当复习索引，不在这里展开推导。

## 偏差、方差与不平衡

- 偏差和方差描述的是不同的误差来源。
- 类别不平衡的处理包括欠采样、过采样，以及 MetaCost、Focal Loss 这类算法侧方法。
- 不平衡时要同时看 ROC 和 PR。NLP 场景还可以用 UDA、EDA 做数据增强。
