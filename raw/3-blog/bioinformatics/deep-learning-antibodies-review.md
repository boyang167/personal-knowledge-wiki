## 摘要

继 CV/NLP 领域的成功后，深度学习开始逐步进入生物领域，例如细胞影像分类、基因组研究等。在药物研发及蛋白工程领域，设计具备成药潜力的分子是重要的目标；AI 与小分子药物结合的研究已较多，目前 AI 方法亦逐渐被用于生物药物的研发，例如**抗体药物**。

本篇综述简要介绍了抗体及深度学习的背景，然后深入介绍了数种深度学习算法，该类算法主要用于**抗体结构 / Affinity / 互作 / Target** 研究等。

## 第 1 部分 · 背景介绍

单克隆抗体治疗在肿瘤、自身免疫等适应症中份额持续增加；噬菌体/酵母展示等体外技术缩短了候选发现周期，但**可开发性**（溶解度、免疫原性等）与**亲和力优化**仍常依赖多轮实验。

**In silico** 抗体工程试图用算力换时间与成本：快速扩增候选、面对难抗原、引入理性设计。与传统杂交瘤或展示筛选相比，纯计算管线若真能落地，则在规模与成本上优势明显；但经典 in silico 方法在关键步骤上仍不尽人意。综述认为，**深度学习**在结构建模、互作预测、表位识别等挑战上，比传统能量函数/统计势路线展现了更高天花板。

从抗体药物的重要性入手，引入计算方法可以提高优化速度、更好地设计抗体、降低成本等——这正是该综述展开三类任务与方法 catalog 的动机。

## 第 2.1 部分 · 基础概念：抗体

抗体是免疫应答产生的蛋白，由两条重链、两条轻链组成。重链含三个恒定域与一个可变域；轻链含一个恒定域与一个可变域。**可变区**形成结合表面（**paratope**），其核心是 **互补决定区（CDR）**：轻链 L1–L3、重链 H1–H3，共六条环（见图 1，综述 PDB: 1A4J）。

CDR 多样性决定抗体对广泛靶点的高特异性，也使抗体成为药物设计焦点，并推动 **in silico** 分析需求。

### 计算挑战一：结构，尤其是 H3

实验结构（X 射线、NMR、Cryo-EM）昂贵耗时，计算建模成为桥梁。对 benchmark 集，多数 CDR 已有较好预测，但 **H3 CDR** 仍是难点：

- H3 编码基因独立，经 **V(D)J 重排** 产生序列与构象双重重度可变；
- 其他 CDR 常可归入**规范簇（canonical clusters）**，同源建模相对可行；H3 往往缺乏足够同源模板。

**社区帖归纳**：系统介绍抗体结构，并引出 CDR 中 **H3** 较特殊、预测较难，是第一个挑战。

### 计算挑战二：抗体–抗原界面

一般 **PPI** 界面往往由长期共进化塑造，疏水/芳香残基富集、 backbone–backbone 氢键较多。抗体–抗原结合是**临时装配**的 ad-hoc  binder：抗原侧未必具备典型 PPI 特征，疏水作用更少，氢键多来自侧链， aromatic hotspot + 短链亲水残基的极性接触更常见（见图 2：myoglobin、actin–profilin PPI vs TSH 受体–抗体）。

因此：

- **挑战二**（社区帖）：预测抗体与抗原间的结合，因互作模式与一般 PPI 不同而更难；
- 不能把通用 PPI docking/打分直接当作抗体专用金标准。

## 第 2.2 部分 · 基础概念：深度学习

深度学习是机器学习子集，强调从**低层原始表示**提取**高层抽象特征**（类似 CV 从像素学到边缘/物体）。

典型前馈网络：输入层 → 多个隐藏层 → 输出层；训练通过反向传播调整连接权重，用**代价函数**（分类常用交叉熵，回归常用 MSE）衡量误差。实践上使用 **训练 / 验证 / 测试** 划分；**早停**等策略缓解过拟合。

抗体相关任务可自然映射到三类（综述 §3.1–3.3，社区帖与之对应）：

| 序号 | 任务 | 含义 |
|------|------|------|
| （1） | **序列 → 结构建模** | 由序列得 3D，含 CDR / 全蛋白折叠 |
| （2） | **预测相互作用及 docking 等** | 是否结合、复合物姿态、亲和力成熟 |
| （3） | **辨别靶点** | 表位 / 结合位点，尤其 B 细胞表位 |

表示形式多样：**序列**可当「语言」喂给 RNN；**图**（原子/残基为点、相互作用为边）、**3D 体素（voxel）**、**流形/表面 mesh** 可把结构问题写成 CV 式输入。

## 第 3 部分 · 为什么需要深度学习？

传统路线依赖：

- **物理力场**（physics-based）：化学细致，但全原子模拟极耗算力，力场难覆盖全部生物复杂性；
- **统计势 / 知识库能量**（knowledge-based）：快，但难刻画高阶非线性模式。

深度学习可在**可微框架**里学习复杂特征组合。CV 中几何深度学习、CNN 的成功表明：把蛋白表示成 **graph、3D voxel、manifold**，再用卷积或图网络提取特征，是可行路径（社区帖：graph / 3D voxel / manifold，经领域数据训练后适配生物学）。

同时，**序列**侧可用 RNN/LSTM/Transformer 处理「氨基酸语言」。注意：模型对数据分布敏感，存在**对抗样本**与**虚假相关**风险——生物学里表现为错误负样本、聚类泄漏等。

## 第 4.1 部分 · 深度学习方法：sequence to structure

### 抗体结构预测：CDR 与 H3

- **主线**：从序列预测 **CDRs**，尤其是 **H3**。
- **同源建模**：对 **non-H3 CDRs**，因规范簇结构相似，预测性能已较好；训练常用高分辨率抗体 **PDB** 结构。
- **传统机器学习**：**GBM**、**PSSM** 等用于 non-H3 CDR 规范簇分类（综述 [27,28]）。

### DeepH3（深度学习代表）

**DeepH3**（Ruffolo et al.）用深度残差网络预测残基对之间的：

- 距离 **d**（Cβ，甘氨酸用 Cα）；
- 方向角 **θ, ω**（二面角）、**φ**（平面角）。

对建模算法生成的 H3 **decoy** 构象打分排序，选最可能构象。训练数据来自 **PyIgClassify**（人/鼠 H3），**SAbDab** 取 1462 结构，5% 作验证。

报告指标示例：距离/角度 Pearson **r** 达 0.79–0.87 量级；相对 Rosetta Energy 平均约 **0.48 Å** 改善；判别分数 **D** 在多个 benchmark 上更优（个别 case study 有互有胜负）。

社区帖要点：**基于残基间距离和方向角，预测 H3 环潜在结构并排序选最优**——与上文一致。

### 一般蛋白结构预测（可迁移）

综述在抗体之外系统介绍三类深度学习方法，思路各异：

#### AlphaFold（第一代综述语境）

- 用 PDB 结构训练网络预测残基 Cβ 距离，再梯度下降优化势函数；
- 数据：PDB + **CATH** 35% 聚类代表，约 29k 训练 / 1.8k 测试；
- **CASP13** free modeling 域表现领先。
- 局限：依赖 **多序列比对（MSA）**，不同蛋白上 MSA 质量差异大。

#### Recurrent Geometric Network（RGN）

- **仅序列输入** → RNN 预测 backbone 扭转角 → 逐残基搭建结构 → **dRMSD** 反向传播优化；
- **CASP11**：FM 类别 dRMSD 优于各 automated server，TM-score 并列最佳；
- 见解：框架区与非 H3 CDR 扭转角可先解出，经 RNN **向 H3 传播上下文**——小改即可专用于 H3。

#### trRosetta

- 序列 + MSA → 深度残差 CNN 预测距离/取向 → **Rosetta** 组装；
- PDB 训练约 15k 链；**CASP13** FM 平均 TM-score **0.625**，高于顶尖 server/human 组；
- 对 **de novo 设计蛋白** 的预测往往优于天然蛋白。

社区帖归纳：**AlphaFold 系列、Recurrent Geometric Network、trRosetta**，方法路线不同——均已覆盖。

## 第 4.2 部分 · Interaction prediction 及 Affinity maturation

### Mason 等 · 序列优化抗体

- 在既有治疗性抗体 **H3 CDR** 引入突变，得到约 **5×10⁴** 变体，实验筛 binding；
- **LSTM / RNN / CNN** 预测 binding 标签；
- 在 **7.2×10⁷** 计算序列中筛出 **3.1×10⁶** 预测 binder；随机抽 30 条实验验证**全部结合**，其中 1 条亲和力提升约 **3 倍**。
- 对比：结构模型给出的 binding 空间远小于真实空间，自由能估计不足以当可靠分类器；**序列法数据更便宜**（NGS），但**按单一抗原训练，难跨靶点泛化**。

### Ens-Grad

- **6 个神经网络集成**（5 个 CNN），数据来自**噬菌体展示 panning** 的富集实验；
- 损失：MSE 回归富集度，或 BCE 分类逐轮 enriched 的 H3；
- 训练后用 **gradient ascent** 对**输入序列**（而非权重）优化，最大化预测粘附性/富集；
- 生成序列可超过种子与训练集富集水平，提示学到高层 binding 特征；
- 相对 VAE、遗传算法等优化器表现更好（需区分是优化策略还是网络容量差异）。

社区帖：**ensemble 6 个网络 + gradient ascent，预测序列表达粘附性；噬菌体文库数据；更丰富种子序列与高层特征**。

### DeepInterface

- **结构方法**：对 docking 姿态分类真/假复合物；
- 界面周围固定盒子 → **体素网格（voxel grid）** 输入；质心连线对齐某一坐标轴缓解旋转歧义；
- **ZDOCK** 采样错误姿态作 **negative samples**；
- 四层 CNN + 全局池化 + 全连接；benchmark 分类准确率约 **75%**。
- 局限：体素尺寸固定、旋转歧义难完全消除；抗体–抗原界面分布偏移可能导致 OOD；但架构对界面类型相对**agnostic**。

社区帖：**voxel grid 构造输入 + 负样本 + CNN 分类 protein complexes**。

### MaSIF-Search

- **几何深度学习**：蛋白表面 mesh 上取 geodesic **patch**，标注曲率、静电、疏水性等；
- patch 映射到 5×16 极角网格，**测地卷积** 得 **1D 表面指纹**；旋转 max-pooling 消歧；
- **Triplet loss**：拉近正样本 patch 描述子，推远负样本；
- 报告 PPI 分类 ROC AUC 可达 **0.99**（几何+化学特征）；低形状互补性子集下降至约 **0.73–0.81**；
- 训练混合抗体–抗原与一般 PPI；**mCSM** 显示专精抗体–抗原突变时相关性高于纯 PPI 集（0.53 vs 0.35）。

社区帖：**从 protein graph/表面取 patch → 1D 表示；最小化正样本距离、最大化负样本距离**。

### TopNetTree

- 把 **抗体–抗原结合** 视作 **PPI 特殊 case**；
- **持久同调（persistent homology）** + 元素特异 barcode，将 3D 结构压成 **1D 拓扑特征**（空腔、环、原子对等），拼接 SASA、电荷等；
- 突变特征 = 野生型与突变型拼接；CNN 提取一层 barcode → **GBDT** 预测 **ΔΔG**；
- SKEMPI2 上：仅用 PPI 训练、抗体–抗原测试 **Rp≈0.53**，RMSE≈1.45 kcal/mol；纯 PPI 交叉验证 **Rp≈0.82**——说明**必须区分抗体界面**。

社区帖：**持久同调 → 多角度 1D 特征 → CNN 输入**，与亲和力突变预测一致。

## 第 4.3 部分 · Target identification

### Antibody Specific B-Cell Epitope Predictions（Jespersen 等）

- **结构方法**：patch = 中心残基 + 6 Å 内暴露邻居；
- 几何：**Cα PCA** + **Zernike moments**（类似 CNN 滤波分解形状）；组成：溶剂暴露、氨基酸统计；
- 标签：patch 与真实表位残基的 **overlap 比例**（0–1）；
- 负 patch：Monte Carlo 扩缩邻居；负 paratope–epitope 对：跨 cluster 错配；
- 三模型：**full**（表位+paratope+Zernike）、**minimal**（无 Zernike）、**antigen-only**；
- **F_rank**：负样本排在真阳性之前的比例——full **7.4%** 优于 minimal 10.9%、antigen 15%，说明**有 paratope 信息时表位更易预测**。

社区帖：**residue + 暴露 neighbors → 1D 特征 + CNN，预测 overlap 比例**。

### MaSIF-site

- 与 MaSIF-Search 同源 fingerprint，接 application-specific 层；
- 相互作用 patch 分类 ROC AUC 约 **0.87**（按蛋白平均）；
- 大疏水 patch 0.87，小疏水 0.81——与抗体界面疏水较弱相关，但仍能区分突变产生的新表位。

社区帖：**表面位点 1D fingerprint + 专用层，做相互作用分类**。

### 线性 B 细胞表位：DRREP、Saha 等

- 约 **90%** B 细胞表位为构象型，但**线性表位预测**研究仍多；
- **Saha 等**：RNN 输入氨基酸序列，准确率约 **65.93%**（700 序列训练）；
- 固定长度 20、两层全连接 + softmax：约 **68.33%**；
- **DRREP**（Sher 等）：随机 **k-mer**「卷积」+ 池化 + **ridge regression** 解析求第三层权重 → **残基级** epitope 概率；在 SARS、HIV、Pellequer、AntiJen、SEQ194 等集上多为深度学习中最优之一（综述 Table 1）。

社区帖：**DRREP 与 Saha 等方法，序列或定长窗口 → 神经网络 → epitope 概率**。

## 第 6 部分 · 讨论与展望

### 抗体–抗原是「特殊 PPI」

- 五个 CDR 中除 H3 外多具**规范结构**，可把建模精力聚焦 H3；
- 抗体可定义**公共轴向**，有助于缓解体素表示的旋转歧义（综述 [59]）；
- 但数据分布、疏水互补、负样本定义仍不同于一般 PPI——**TopNetTree、mCSM** 等已用数字说明性能差距。

### 数据、迁移学习与聚类划分

- 各方法常用**不同子集、不同划分协议**，横向对比困难；希望像 ImageNet 一样出现统一基准（**CASP/CAPRI** 持续重要）；
- **迁移学习**：先在一般 PPI/折叠数据上预训练，再用少量抗体–抗原微调（膜蛋白 folding 网络已有先例）；
- **BLAST/HMMER/FATCAT** 等相似性工具用于聚类，避免同源序列泄漏进测试集；
- 晶体分辨率、柔性区（尤其 H3）未解析区块降低标签质量；**亲和力实验条件**不一致影响回归标签。

### 负样本难题（社区帖 + 原文）

- 抗体理论上可结合抗原表面多处，「未见结合」≠「不能结合」；
- **DeepInterface** 依赖 docking decoy 质量；差 decoy 太易被识破；
- **MaSIF** 类方法弱化复合物相对取向，负样本风险略低，但表位级标签仍难。

### 挑战（社区帖原文条目）

- 序列数据不够大量  
- 结构数据很少  
- 负样本很难确定  
- 无标准数据集  

### 未来方向（社区帖原文条目）

- 结构的表示  
- 标准数据集的构建  
- 生成方法  
- 分子动力学  

综述 **§7.1** 进一步展开：

1. **结构表示**：几何深度学习、局部坐标系、旋转不变性，缓解体素稀疏与边界尺寸限制。  
2. **标准基准**：类比 ZINC/ChEMBL、MNIST/ImageNet，需要大规模可复现切分。  
3. **生成模型**：小分子生成成熟，蛋白/抗体** paratope 对 epitope 生成**仍难（尺寸与构象空间更大）。  
4. **深度学习 × MD**：加速力场、采样，综述指向 ML+MD 专题文献 [71]。

### 总体看法（社区帖）

深度学习分析生物学数据需要新的模型结构和方法；现有问题可同时利用**序列 / 结构 / 相互作用 / 属性相似性**等数据。抗体–抗原结合预测常缺通用数据集，需持续建设基准；**迁移学习**可用相似蛋白数据；建模要考虑 **affinity**、**负样本构造**等。

## 附录 A · 综述结论（英译要旨）

深度学习已成为生物化学与药物发现的重要组成部分。抗体高亲和、高特异，迫切需要**专门适配**的算法。然而：

- 结构数据量远低于序列数据；
- **阴性数据**难获取、难证伪，计算负样本亦难保证真实；
- 各模型训练集不一致，难以判断何种架构最适合给定任务。

随着数据与方法增加，对抗体药研发的认知会逐步转化为可用药分子；**深度学习 + 抗体科学**仍有很大空间。
